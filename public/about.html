เกี่ยวกับเรา

Cough Code คืออะไร

โครงการต้นแบบที่ทดลองใช้เสียงไอร่วมกับอาการทางคลินิก เพื่อคัดกรองสุขภาพทางเดินหายใจเบื้องต้น

แนวคิดของโครงการ

Cough Code พัฒนาขึ้นเพื่อทดลองแนวทางคัดกรองสุขภาพทางเดินหายใจที่เข้าถึงง่าย โดยใช้ลักษณะเสียงไอร่วมกับอาการที่ผู้ใช้รายงานเอง ประมวลผลเป็นแนวโน้มเบื้องต้นสำหรับกลุ่มอาการที่พบบ่อย 4 กลุ่ม ได้แก่ RSV ไอกรน ปอดบวม และอาการทางเดินหายใจอื่น ๆ เพื่อช่วยให้ผู้ใช้ตัดสินใจได้เร็วขึ้นว่าควรพบแพทย์หรือไม่

เราไม่ใช่เครื่องมือวินิจฉัย

เครื่องมือนี้เป็นต้นแบบสำหรับการคัดกรองเบื้องต้นเท่านั้น ไม่ได้ผ่านการรับรองทางการแพทย์ และไม่สามารถใช้แทนการตรวจวินิจฉัยโดยแพทย์ได้ ผลลัพธ์ที่ได้ควรใช้เป็นข้อมูลประกอบการตัดสินใจ ไม่ใช่ข้อสรุปสุดท้ายของสุขภาพผู้ใช้งาน

เริ่มประเมินอาการ

เครื่องมือนี้เป็นการคัดกรองเบื้องต้น ไม่สามารถวินิจฉัยแทนแพทย์ได้
